# 诗音（Shiyin）

一个跨端音乐播放器：网页版与安卓 App 共用同一套代码，导入本机音频真实播放，音频只保存在设备本地，不上传任何服务器。

- 在线网页版：<https://xiaoyu-hue.github.io/shiyin/>
- 安卓安装包：[GitHub Releases](https://github.com/xiaoyu-hue/shiyin/releases)
- 项目文档：[docs/](docs/)（产品需求 / 架构设计 / 实施计划）

## 功能亮点

### 音乐库与播放

- 四个主视图：主页、搜索、音乐库、我的
- **音乐库**：按歌曲 / 专辑 / 歌手 / 歌单四种方式浏览，歌曲可按导入时间、歌名、歌手排序，专辑与歌手有详情页
- **自建歌单**：新建、改名、删除歌单，通过单曲「…」菜单把歌加入歌单
- **播放队列**：显式队列（点哪个列表就按哪个列表排队），播放页可打开队列拖拽排序、移除、清空；单曲菜单支持「下一首播放 / 加入队列」，队列防重复添加（已在队列的歌改为移动位置）
- **单曲管理**：行尾「…」菜单含收藏与删除（真删除并连带清理收藏、历史、歌单与队列，二次确认）
- 迷你播放条 + 全屏播放器：切歌、播放 / 暂停、三种播放模式、收藏、进度拖动
- **睡眠定时**：播放页可设 15 / 30 / 45 / 60 分钟后停播或「播完这首就停」，按钮实时显示剩余时间，迷你条有定时标记
- **偏好持久化**：收藏、最近播放历史（上限 100 条）、主题选择与外观模式自动保存，刷新或重开后恢复

### 歌词

- **内嵌歌词解析**：导入时读取音频文件内嵌歌词，支持带时间戳的 LRC 同步歌词（逐行高亮、点击跳转、高亮行平滑滚动居中）与纯文本歌词
- **外挂歌词导入**：没有内嵌歌词的歌曲可配 .lrc / .txt 歌词文件——导入音频时同名文件自动配对，也可在单曲「…」菜单或歌词页单独补挂；自动识别 UTF-8 / GBK / UTF-16 编码，挂上后持久化保存
- **歌词海报**：在歌词页点选最多 6 行歌词，本地生成 1080×1440 海报图（封面色彩场 + 歌名 + 歌词），可保存或系统分享

### 界面与主题

- **液态玻璃界面**：悬浮玻璃胶囊导航与迷你播放条、播放页封面取色光晕 + 玻璃控制面板、歌词页玻璃层；玻璃带一点当前主题的染色，七套主题各有气质；播放页可下拉关闭、迷你条可横滑切歌；不支持背景模糊的设备自动降级为实底
- 七套内置主题即时切换，默认「纯净白」
- **封面氛围与歌词主角（1.4.0）**：播放页/歌词页背景按当前封面生成弥散色彩场、切歌交叉淡化；歌词当前行放大并随演唱进度扫色；主页为大字问候 + 横滑卡片轨的编辑排版
- **深色模式**：外观三档（跟随系统 / 浅色 / 深色），每套主题配深色底色，玻璃与文字颜色全站语义令牌驱动
- **流畅模式**：可关实时模糊换不透明填充，低性能设备滚动与切页更顺

### 安卓 App

- 系统文件选择器多选导入；锁屏 / 通知栏媒体控制（上一首 / 暂停 / 下一首与封面）；息屏后台播放；首次启动有电池设置引导，避免被系统省电管理中断播放
- **层级返回**：系统返回手势按层级收起界面（弹层 → 播放页 → 二级页 → 切后台保播放），不直接退出
- 全面屏安全区与系统栏图标明暗随 App 主题联动；切歌、收藏、设定睡眠定时等关键操作带轻震反馈；启动屏与首帧同色衔接，无白屏闪
- **封面缩略图与预模糊氛围背景**：列表与播放页用按尺寸生成的图，滚动更省资源
- **交互手势**：播放页封面横滑切歌、点封面两侧快退 / 快进 10 秒（全屏滑动切歌可在设置开启）；迷你条上滑展开播放页；长按多选批量入队 / 加歌单 / 删除；列表行右滑「下一首播放」；长列表快速滚动条；首次打开且曲库为空时有导入引导

### Windows 桌面版

- Tauri 承载同一套界面与逻辑，安装包只有约 3.6 MB；曲库存为应用数据目录里的真实文件加索引
- 系统对话框多选或把文件直接拖进窗口导入（含同名歌词配对）；关窗口缩到系统托盘继续播放，再点托盘图标唤回
- 系统媒体键（播放 / 暂停 / 上一首 / 下一首）可用；设置里可开「开机时自动启动」
- **宽屏桌面布局（1.4.0）**：窗口拉宽后左侧出现导航栏、播放页变为左右双区（大封面 + 控制列）、歌词居中限宽；支持空格播放/暂停、方向键快退/快进、Esc 逐层返回
- **应用内自动更新**：启动时自动检查新版，设置页也能手动检查，点一下就下载安装并重启到新版，不用重新下载安装包

### 本地与隐私

- 音频、元数据、封面与歌词只保存在设备本地：网页存于 IndexedDB，App 存为应用私有文件加索引，不上传任何服务器
- **数据管理**：设置页可查看本地音乐占用，并可一键清除全部本地音乐（设备里的原文件不受影响）
- 加载态、错误态、空态与错误边界齐备

## 安装与使用（使用者）

### 网页版

打开在线网页版即可使用，无需安装。在浏览器里导入的音乐保存在该浏览器的站点数据中，清除浏览器站点数据会同时清除已导入的音频。

### 安卓 App

安装包在 [GitHub Releases](https://github.com/xiaoyu-hue/shiyin/releases) 下载（1.0.0 起），系统要求 Android 7.0 及以上。

- 首次安装时，系统会要求允许浏览器 / 文件管理器「安装未知应用」，允许后即可安装。
- 后续版本均为同一签名，下载新版 APK 直接覆盖安装即可，曲库、歌单与设置都会保留。
- App 内暂无自动更新，看到新版本发布后按上面方式覆盖安装。

### Windows 桌面版

安装包在 [GitHub Releases](https://github.com/xiaoyu-hue/shiyin/releases) 下载（1.3.0 起，文件名形如 `Shiyin_1.3.1_x64-setup.exe`），系统要求 Windows 10 / 11。

- **首次运行会弹蓝色提示窗**：安装包未做商业代码签名，Windows SmartScreen 会提示「Windows 已保护你的电脑」。点「**更多信息**」→「**仍要运行**」即可，只需这一次，之后打开不再提示。
- 装好后从开始菜单或桌面图标打开；导入音乐用左上角导入按钮，或把音频文件直接拖进窗口。
- 后续版本不用重新下载：应用启动时会自动检查更新，设置页「桌面版」一栏也能手动检查，一键更新。
- 已知限制：系统音量浮层等系统媒体弹窗里，应用身份显示为 WebView2 的名字（功能不受影响，媒体键可用）；真实听感与窗口观感等体验项尚未经实机人工验收（功能完整性由自动化验收在真实 Windows 机器上把关）。

### 导入音乐与音频说明

- 支持 mp3 / m4a / wav / flac / ogg，文件只在本机读取与存储，不会上传。
- 导入时读取音频文件内嵌的歌名、歌手、专辑、封面图与歌词（ID3 / Vorbis Comment / MP4 等格式）；标签缺失的字段才回退文件名推断，约定「歌手 - 歌名」格式，无法识别时歌手记为「本地音乐」。
- 封面在列表、迷你播放条与全屏播放器三处展示；文件里没有内嵌歌词时，可用外挂歌词导入补挂（见「功能亮点 · 歌词」）。
- 标签解析在本地完成（解析库按需动态加载，不影响首屏），解析失败不阻断导入。
- 应用不内置任何示例曲目，曲目全部来自你导入的本地音乐；未导入时各页面显示空状态引导。

## 本地开发（开发者）

要求 Node.js 22+。

```bash
npm install         # 安装依赖
npm run dev         # 开发服务器
npm run build       # 类型检查 + 生产构建（网页版）
npm test            # 运行单元测试
npm run preview     # 预览构建产物
npm run build:native  # 类型检查 + 安卓用构建（相对路径 base）
npx cap sync android  # 把构建产物与插件同步进 android/ 工程，再用 Android Studio 打包
npm run build:desktop # 类型检查 + 桌面用构建（相对路径 base）
npx tauri build       # Windows 桌面打包（需 Rust 工具链；正式发版走 GitHub Actions 的 windows-release 工作流）
```

### 技术栈

| 层次 | 选型 |
| --- | --- |
| 界面 | React + TypeScript |
| 构建 | Vite |
| 样式 | Tailwind CSS（主题令牌驱动） |
| 状态 | Zustand（四个 slice） |
| 动画 | Motion |
| 图标 | Lucide |
| 测试 | Vitest |
| 持久化 | 网页：IndexedDB；App / 桌面：本地文件 + JSON 索引 |
| 元数据 | music-metadata（内嵌标签、封面与歌词解析，按需动态加载） |
| 移动端 | Capacitor（安卓打包、媒体会话与原生文件能力） |
| 桌面端 | Tauri 2（Rust 壳：托盘 / 单实例 / 文件桥 / 自动更新 / 开机自启，界面与逻辑与网页共用） |

平台相关能力（主题注入、音频播放、曲目存储、文件选择）收口在 `src/platform/`，按运行环境分流实现，上层业务不感知平台差异。

### 目录结构

```
src/
├── data/        类型、主题数据与纯查询逻辑
├── lib/         纯函数：格式化、播放策略、歌词定位、主题映射、文件解析、动效配置
├── store/       Zustand 状态（player / ui / collection / theme 四切片）+ 启动装配
├── platform/    平台能力接口与双实现（StyleAdapter / AudioEngine、曲目存储网页/原生分流）
├── hooks/       useTheme
├── components/  视图组件、ui 基础组件、common 通用态组件
└── App.tsx      根组件组装
```
